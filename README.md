# UMSI Engaged Learning Student Resource Portal

SI 539 Client Project · Fall 2026

Open this `client_project_starter_f26-main` folder in VS Code and preview `index.html` from this folder. The four pages share the files in `css/` and `js/` and load their photos from `images/`. Keep those directories next to the HTML pages when copying or publishing the site.

| File | Page |
| --- | --- |
| `index.html` | Home |
| `prep.html` | Preparing for Your Experience |
| `start.html` | Starting Your Experience |
| `study.html` | Student Research Opportunities |
| `404.html` | Custom page for missing URLs |

The local starter folder is a separate working copy. For the existing GitHub Pages site, publish these pages, including `404.html`, and their asset directories together at the configured publishing root. Open `404.html` directly for a preview, or use a host configured to serve it for missing URLs.
